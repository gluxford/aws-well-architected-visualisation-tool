# Well-Architected Report Visualizer - Architecture Diagram Instructions

## Overview
This document provides detailed instructions for creating a professional architecture diagram for the Well-Architected Report Visualizer using draw.io (diagrams.net).

## Step 1: Set Up the Canvas
1. Go to https://app.diagrams.net/ or open the desktop application
2. Create a new diagram
3. Select "Blank Diagram"
4. Set page size to "Letter" or "Custom" (1100 x 850 pixels works well)
5. Set orientation to "Landscape"

## Step 2: Add AWS Icons
1. Click on "More Shapes..." at the bottom of the left sidebar
2. Check "AWS / Amazon Web Services / AWS 19" or "AWS Architecture 2021" library
3. Click "Apply"

## Step 3: Create the Main Components

### User/Browser
- Drag the "User" icon from the AWS General Resources category
- Position it on the left side of the diagram
- Label it "User Browser"

### AWS Services
- S3 Bucket:
  - Drag the "S3" icon from the AWS Storage category
  - Position it to the right of the User
  - Label it "S3 Website Bucket"

- CloudFront (Optional):
  - Drag the "CloudFront" icon from the AWS Networking category
  - Position it above the S3 bucket
  - Label it "CloudFront Distribution (Optional)"
  - Use a dashed line to connect it to the S3 bucket

- API Gateway:
  - Drag the "API Gateway" icon from the AWS Application Integration category
  - Position it to the right of the S3 bucket
  - Label it "API Gateway"

- Lambda:
  - Drag the "Lambda" icon from the AWS Compute category
  - Position it to the right of the API Gateway
  - Label it "Lambda Proxy"

- Well-Architected API:
  - Drag the "AWS Well-Architected Tool" icon from the AWS Management & Governance category
  - Position it to the right of the Lambda
  - Label it "AWS Well-Architected API"

### CloudFormation Stacks
- Master Stack:
  - Use a rectangle shape
  - Color it blue (#1E88E5)
  - Label it "Master Stack"
  - Position it at the bottom of the diagram

- Infrastructure Stack:
  - Use a rectangle shape
  - Color it blue (#1E88E5)
  - Label it "Infrastructure Stack"
  - Position it to the right of the Master Stack

- Lambda Stack:
  - Use a rectangle shape
  - Color it blue (#1E88E5)
  - Label it "Lambda Stack"
  - Position it to the right of the Infrastructure Stack

- Content Stack:
  - Use a rectangle shape
  - Color it blue (#1E88E5)
  - Label it "Content Stack"
  - Position it to the right of the Lambda Stack

## Step 4: Add Connections and Flow

### User Flow
1. User to S3:
   - Connect User to S3 with an arrow
   - Label it "1. Access Website"

2. S3 to API Gateway:
   - Connect S3 to API Gateway with an arrow
   - Label it "3. Make API Calls"

3. API Gateway to Lambda:
   - Connect API Gateway to Lambda with an arrow
   - Label it "4. Invoke Lambda"

4. Lambda to Well-Architected API:
   - Connect Lambda to Well-Architected API with an arrow
   - Label it "5. Call Well-Architected API"

### Return Flow (use dashed lines)
1. Well-Architected API to Lambda:
   - Connect with a dashed arrow
   - Label it "6. Return Assessment Data"

2. Lambda to API Gateway:
   - Connect with a dashed arrow
   - Label it "7. Return with CORS Headers"

3. API Gateway to S3:
   - Connect with a dashed arrow
   - Label it "8. Return JSON Response"

### CloudFormation Deployment
1. Master Stack to other stacks:
   - Connect Master Stack to each of the other stacks
   - Label connections "Orchestrates"

2. Infrastructure Stack to resources:
   - Connect to S3 and CloudFront
   - Label connections "Provisions"

3. Lambda Stack to resources:
   - Connect to API Gateway and Lambda
   - Label connections "Provisions"

4. Content Stack to S3:
   - Connect to S3
   - Label connection "Deploys Files"

## Step 5: Add AWS Cloud Boundary
1. Draw a large rectangle around all AWS services
2. Label it "AWS Cloud"
3. Use a light gray fill with dashed border

## Step 6: Add Legend
1. Create a small box in the corner
2. Add color-coded items explaining:
   - AWS Services (orange)
   - CloudFormation Stacks (blue)
   - Data flow direction
   - Optional components (dashed lines)

## Step 7: Export the Diagram
1. Go to File > Export as > PNG
2. Set resolution to at least 300 DPI
3. Check "Transparent Background"
4. Save as "architecture-diagram.png"

## Additional Tips
- Use consistent spacing between components
- Align components to a grid
- Use AWS standard colors (orange #FF9900 for services)
- Keep text concise and readable
- Use numbered arrows to show the sequence of operations
- Group related components visually

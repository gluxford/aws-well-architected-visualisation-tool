Instructions for creating the Well-Architected Report Visualizer architecture diagram in draw.io:

1. Open draw.io (https://app.diagrams.net/)

2. Create a new diagram and select "Blank Diagram"

3. Add AWS icons from the library:
   - Click on "More Shapes..." at the bottom of the left sidebar
   - Check "AWS / Amazon Web Services / AWS 19" library
   - Click "Apply"

4. Create the diagram with the following components:

   USER SIDE:
   - Add a "User" or "Client" icon
   - Connect to CloudFront (if used) or directly to S3

   AWS RESOURCES:
   - CloudFront Distribution (optional)
   - S3 Bucket (for website hosting)
   - API Gateway
   - Lambda Function
   - AWS Well-Architected API (use the AWS Well-Architected icon)

   CLOUDFORMATION:
   - Add CloudFormation icon
   - Show the stack hierarchy with nested stacks

5. Add numbered flow arrows to show the request/response path:
   1. User accesses website (S3 via CloudFront or direct)
   2. Browser loads web application
   3. Web app makes API calls to API Gateway
   4. API Gateway invokes Lambda function
   5. Lambda calls Well-Architected API
   6. Well-Architected API returns data to Lambda
   7. Lambda adds CORS headers and returns to API Gateway
   8. API Gateway returns response to browser
   9. Browser renders visualization

6. Add a legend explaining the components

7. Group related components using containers/boundaries

8. Export as PNG with transparent background

Layout suggestions:
- Place user/browser on the left
- AWS services in the middle
- CloudFormation stacks at the bottom
- Use a left-to-right flow for the main request path
- Use AWS standard colors (orange for services, etc.)
